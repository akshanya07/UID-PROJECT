# PG Management Website

## Project Description
The PG Management Website is designed to simplify shared living for students and professionals. It helps users manage common challenges such as splitting expenses, tracking dues, and assigning household chores.

The platform features:
- Expense management cards
- Chore boards
- Easy input forms
- Organized shared living tools

This system helps users:
- Stay organized
- Maintain transparency
- Collaborate efficiently in a shared living environment
